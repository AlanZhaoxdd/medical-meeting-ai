# Vue 管理端

Vue 3 + TypeScript + Vite + Pinia + Element Plus 管理端，包含注册/登录、KB 管理、文档上传与进度、Block/Chunk 预览、知识审核、发布门禁和混合检索测试台。

```bash
npm install
npm run dev
```

默认通过 Vite 将 `/api`、`/health` 和任务 WebSocket 代理到 `http://localhost:8000`。

```bash
npm test
npm run lint
npm run build
```

完整启动说明见仓库根目录 [README](../README.md)。
